# Python Basics

This exercise covers the basic building blocks of coding in Python. Focus on the underlying algorithmic concepts rather than the exact syntax — ask yourself questions like: What is a string? What kind of behaviour does a for-loop create?

## How to work through it

1. Open the relevant exercise file and find the next `TODO`.
2. Select only the lines for that `TODO` — no more — so you work through the file step by step.
3. Ask Copilot to fill in just the selected lines.
4. Read the generated code and make sure you understand what it does before moving on.

We'll go through all the examples together during class.
